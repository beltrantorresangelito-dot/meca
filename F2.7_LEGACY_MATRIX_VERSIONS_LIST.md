# F2.7 — Listado legacy de versiones fuera de server.js

Se migra:

`GET /api/matriz/versiones`

## Antes

`server.js -> pool.query(versiones_matriz)`

## Después

```text
server.js
   ↓
LegacyMatrixService.listVersions()
   ↓
LegacyMatrixRepository.listLegacyMatrixVersions()
   ↓
PostgreSQL
```

## Contrato preservado

HTTP 200 con array ordenado por `creado_en DESC`.

Cada fila conserva las columnas legacy:

- id
- version
- descripcion
- fecha_vigencia
- activa
- creado_por
- creado_en
- publicado_por
- publicado_en

Sin token: 401.
Error: 500.

## Importante

Todavía NO se filtra por `matriz_id`.

Aunque el nuevo modelo soporta múltiples matrices por Quiebre, el frontend actual consume este endpoint como listado global. Cambiarlo ahora rompería el contrato. El filtrado por matriz se introducirá junto con la adaptación del frontend.
