# F1.6 — Entidad Quiebre

Objetivo: introducir `quiebres` sin modificar todavía el comportamiento actual de Cobranzas.

Quiebre representa la actividad/proceso realizado por el gestor, por ejemplo COBRANZAS o FRAUDE.

En F1.6 se crea la tabla `quiebres` y se registra `COBRANZAS` como primer registro. No se modifica `campanas`, `evaluaciones`, `versiones_matriz`, frontend, Node ni Python.

## Ejecución

```powershell
npm test
npm run db:status
npm run db:migrate
npm run db:status
```

Verificación SQL:

```sql
SELECT id, codigo, nombre, activo
FROM quiebres
ORDER BY id;
```

Debe existir `COBRANZAS`.

Antes de F1.7 puedes validar reversibilidad:

```powershell
npm run db:rollback
npm run db:status
npm run db:migrate
```

F1.6 queda aceptada si los tests pasan, la migración se aplica, existe COBRANZAS y MECA sigue funcionando igual.
