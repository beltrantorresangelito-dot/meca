## Contratos legacy preservados

- meses-disponibles:
  - sin token -> 401;
  - error interno -> 200 + [].
- errores-auditores:
  - sin token -> 401;
  - error -> 500 con estructura vacía y success=false.
- resúmenes:
  - error interno -> 500 + [].
- líderes:
  - sin validación de token dentro del handler, igual que antes.
- evolutivo:
  - periodo default `dia`, todavía sin modificar el dataset.
- evaluaciones-con-detalles:
  - conserva N+1 deliberadamente.
