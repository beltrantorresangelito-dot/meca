# F2.11-C — Escrituras Matrix: Submotivos

Se extraen:

- POST `/api/matriz/sub-motivos`
- PUT `/api/matriz/sub-motivos/:id`
- DELETE `/api/matriz/sub-motivos/:id`

## Hallazgos corregidos

1. DELETE legacy todavía consultaba/borraba `sub_motivos`, tabla no vigente.
2. Supervisor ya llama `API.actualizarSubMotivo(id, data)`, pero server.js no
   tenía PUT explícito para Submotivos.

F2.11-C formaliza el CRUD completo sobre `version_sub_motivos`.

## Reglas

- solo se escribe en la versión activa;
- el atributo debe pertenecer a la versión activa;
- código único dentro del atributo;
- peso > 0;
- suma de pesos de submotivos <= peso_maximo del atributo;
- edición excluye el propio ID al recalcular;
- todas las mutaciones usan transacción/rollback.

## Resultado arquitectónico

Frentes + Atributos + Submotivos ya tienen lecturas y escrituras fuera de
`server.js`.

El siguiente paso recomendado es F2.12:
versionado/congelado/activación/validadores de matriz.
