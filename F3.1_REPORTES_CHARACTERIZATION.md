## Contratos que deben preservarse

### `/api/reportes/kpis`
- GET.
- Devuelve directamente filas completas de `evaluaciones`.
- Orden: `timestamp DESC`.
- Error: HTTP 500 + `{error}`.

### `/api/reportes/ranking`
- Actualmente devuelve el mismo dataset que `kpis`.
- Esto puede parecer redundante, pero F3 no lo cambia.

### `/api/reportes/meses-disponibles`
- Exige token dentro del handler.
- Lee `fecha_formateada`.
- Convierte fechas DD/MM/YYYY a meses únicos.
- Orden más reciente primero.
- Peculiaridad: ante error de BD devuelve **HTTP 200 + []**.

### `/api/reportes/evolutivo`
- Acepta `periodo`, default `dia`.
- Actualmente el valor de `periodo` no modifica la consulta SQL.
- Devuelve `evaluaciones` por `timestamp ASC`.
- F3 debe conservarlo inicialmente.

### `/api/reportes/top-fallas`
- Devuelve `detalles_evaluacion` donde `cumple = false`.

### `/api/reportes/errores-auditores`
- Exige token.
- Filtros: `periodo`, `auditor`.
- Solo detalles incumplidos.
- Normaliza fechas.
- La forma agregada de respuesta debe conservarse exactamente.

### `/api/reportes/evaluaciones-con-detalles`
- Une evaluaciones con detalles.
- Debe conservar la forma enriquecida actual.

### `/api/reportes/lideres`
- Exige token.
- Usa `agentes.lider_2026`.

### Resúmenes
- `/resumen-por-lider`
- `/resumen-por-ubicacion`
- `/resumen-por-localidad`

Conservan métricas:
- `totalAgentes`
- `totalEval`
- `promedioGeneral`
- `promedioENC`
- `promedioECUF`
- `promedioECN`
- `pctQuiebres`
- `gestoresQ4`
- `pctQ4`

Peculiaridad legacy de los tres:
- error interno -> **HTTP 500 + []**.
