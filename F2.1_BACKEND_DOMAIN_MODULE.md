# F2.1 — Primer módulo backend: Quiebre / Campaña / Matriz

Se crea una frontera backend real sin modificar `server.js`.

```text
Route/Controller
      ↓
DomainService
      ↓
DomainRepository
      ↓
PostgreSQL
```

El Repository concentra SQL. El Service concentra validaciones y errores de dominio.

Incluye:
- listar Quiebres;
- Campañas por Quiebre;
- Matrices por Quiebre;
- historial Campaña↔Matriz;
- resolver contexto de evaluación;
- validar consistencia.

F2.1 no cambia endpoints ni frontend.

## Pruebas

```powershell
npm test
```

## Prueba opcional contra la BD local

```powershell
node -e "const {DomainService}=require('./src/modules/domain'); const {pool}=require('./models/database'); new DomainService().validateConsistency().then(console.log).finally(()=>pool.end())"
```

Debe devolver `ok: true`.

Resolver una campaña:

```powershell
node -e "const {DomainService}=require('./src/modules/domain'); const {pool}=require('./models/database'); new DomainService().resolveContext({campaignId:1}).then(console.log).finally(()=>pool.end())"
```

F2.2 integrará endpoints de lectura concretos con este módulo, preservando los contratos existentes.
