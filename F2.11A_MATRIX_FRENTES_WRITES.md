# F2.11-A — Escrituras Matrix: Frentes

Se extraen del monolito:

- POST `/api/matriz/frentes`
- PUT `/api/matriz/frentes/:id`
- DELETE `/api/matriz/frentes/:id`

## Hallazgo corregido

POST y PUT ya trabajaban con `version_frentes`.

DELETE todavía intentaba operar sobre las tablas antiguas:

- `frentes`
- `atributos`
- `sub_motivos`

Esas tablas ya no existen en la BD vigente.

F2.11-A corrige DELETE para operar únicamente sobre:

- `version_frentes`
- `version_atributos`
- `version_sub_motivos`

## Transacciones

Cada escritura se ejecuta dentro de:

```text
BEGIN
  validaciones
  mutación
COMMIT
```

Ante cualquier error:

```text
ROLLBACK
```

Esto evita modificaciones parciales.

## Reglas preservadas

### Crear frente
- exige código, nombre y peso;
- peso > 0 y <= 100;
- exige versión activa;
- código único dentro de la versión activa;
- suma de pesos de frentes no puede superar 100%.

### Actualizar frente
- solo modifica un frente perteneciente a la versión activa;
- conserva validación de código duplicado;
- conserva límite total de 100%.

### Eliminar frente
- solo elimina un frente de la versión activa;
- elimina primero submotivos versionados;
- luego atributos versionados;
- finalmente el frente;
- todo ocurre en una única transacción.

## Qué no se toca

- Atributos (F2.11-B)
- Submotivos (F2.11-C)
- Versionado/congelado/activación (F2.12)
- BD/migraciones
- frontend

## Pruebas

```powershell
npm test
```

### Prueba funcional recomendada

No uses un frente productivo para probar DELETE.

En Supervisor:
1. crea temporalmente un frente con peso pequeño que no haga superar 100%;
2. edítalo;
3. elimínalo;
4. confirma que desaparece de la versión activa.

Si la matriz actual ya suma 100%, primero prueba edición sobre un frente
existente y deja CREATE/DELETE para una versión de prueba o después de ajustar
temporalmente pesos de forma controlada.

## Criterio de aceptación

- npm test = 0 fail
- creación conserva reglas
- edición funciona
- eliminación funciona sobre tablas versionadas
- rollback comprobado por tests
- Administrador de Matriz sin regresiones
