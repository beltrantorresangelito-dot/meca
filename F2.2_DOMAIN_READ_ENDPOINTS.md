# F2.2 — Endpoints de lectura del dominio

## Objetivo

Integrar el primer módulo backend con `server.js` usando el mapa `routes` que el servidor ya tenía.

No se reemplazan endpoints legacy. Se agregan endpoints nuevos y explícitos para MECA Platform.

## Endpoints

Todos requieren Bearer token válido.

```text
GET /api/domain/quiebres
GET /api/domain/campanas?quiebreId=1
GET /api/domain/matrices?quiebreId=1
GET /api/domain/campana-matriz?campanaId=1
GET /api/domain/contexto-evaluacion?campanaId=1&fecha=2026-08-22
GET /api/domain/consistencia
```

## Flujo

```text
server.js routes map
       ↓
DomainController
       ↓
DomainService
       ↓
DomainRepository
       ↓
PostgreSQL
```

## Qué se modifica

- `server.js`: 2 cambios pequeños:
  1. require de `domain.routes`
  2. `registerDomainRoutes(routes)`

## Qué NO se toca

- endpoints legacy de matriz;
- evaluaciones;
- asignaciones;
- reportes;
- audio;
- frontend;
- PostgreSQL.

## Pruebas

```powershell
npm test
```

Después arrancar MECA y comprobar que Auditor y Supervisor siguen funcionando.

## Prueba manual de endpoints

Desde el navegador con sesión iniciada puede usarse consola:

```javascript
const token = localStorage.getItem('meca_token');

fetch('/api/domain/quiebres', {
  headers: { Authorization: `Bearer ${token}` }
}).then(r => r.json()).then(console.log);
```

Campañas:

```javascript
fetch('/api/domain/campanas?quiebreId=1', {
  headers: { Authorization: `Bearer ${token}` }
}).then(r => r.json()).then(console.log);
```

Contexto:

```javascript
fetch('/api/domain/contexto-evaluacion?campanaId=1', {
  headers: { Authorization: `Bearer ${token}` }
}).then(r => r.json()).then(console.log);
```

Consistencia:

```javascript
fetch('/api/domain/consistencia', {
  headers: { Authorization: `Bearer ${token}` }
}).then(r => r.json()).then(console.log);
```

## Criterio de aceptación

- npm test: 0 fail;
- MECA arranca;
- login Auditor/Supervisor normal;
- endpoints nuevos devuelven 200 con token válido;
- sin token devuelven 401;
- consistencia devuelve `ok: true`;
- endpoints legacy continúan funcionando.
