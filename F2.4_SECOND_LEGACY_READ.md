# F2.4 — Segunda lectura legacy migrada

## Endpoint

`GET /api/evaluacion/version-activa`

Se extrae el SQL de `server.js` al mismo módulo de compatibilidad de matriz creado en F2.3.

## Contrato preservado

### Cuando existe versión activa

HTTP 200 con exactamente las columnas históricas:

- id
- version
- descripcion
- activa
- created_at

### Cuando NO existe versión activa

El endpoint NO devuelve 404.

Conserva su respuesta histórica:

```json
{
  "version": "default",
  "activa": false,
  "message": "No hay versión activa configurada"
}
```

HTTP 200.

## Importante

No se fusiona con:

`GET /api/matriz/versiones/activa`

porque ese endpoint devuelve 404 si no existe una versión activa y además expone `SELECT *`.

Son contratos diferentes aunque consulten la misma tabla.

## Arquitectura

